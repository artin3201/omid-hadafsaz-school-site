# دبستان امید و هدف‌ساز

صفحهٔ اصلی فارسی و راست‌چین با تصویرسازی الهام‌گرفته از معماری و فضای مدرسه در ایران.

نام مدرسه از اطلاعاتی است که سفارش‌دهنده داده است. متن‌های معرفی، خبرها، برنامه‌ها و جزئیات تماس عمومی و قابل‌ویرایش‌اند؛ اطلاعات رسمی مدرسه برای تکمیل آن‌ها باید جایگزین شود. نشانی و راه ارتباطی واقعی در این نسخه وارد نشده‌اند.
