# دبستان امید و هدف‌ساز

صفحهٔ اصلی فارسی و راست‌چین برای معرفی دبستان؛ طراحی واکنش‌گرا با عکس محوطه و حال‌وهوای ایرانی.

نام مدرسه از اطلاعاتی است که سفارش‌دهنده داده است. متن‌های معرفی، برنامه‌ها، خبرها و جزئیات تماس عمومی و قابل‌ویرایش‌اند؛ تا زمانی که اطلاعات رسمی دریافت نشود، نباید به‌عنوان واقعیت‌های تأییدشدهٔ مدرسه تلقی شوند. نشانی و راه ارتباطی واقعی در این نسخه وارد نشده‌اند.
